# Company mapping and source review upgrade

Implementation verified locally on 16 October 2026. This file does not by itself
confirm a cloud deployment; the release owner should record the resulting build
and smoke run in `LAUNCH_STATUS.md` after publishing.

The upgrade makes the existing saved website data easier to use in company-list
and CRM workflows:

- Flat company JSON and spreadsheet-safe CSV, including selected contact fields,
  their source URLs, one social URL per platform and technology names.
- Contact JSON and CSV with one retained contact per website, source pages and
  extraction methods. Shared addresses remain separate between websites.
- A coverage dataset view and structured per-page diagnostics, including failed
  contact URLs inside an otherwise successful website result.
- Email capitalization variants now deduplicate across pages while retaining
  provenance. Browser-challenge contact pages are skipped instead of parsed.

Existing input options, HTTP/DNS/robots restrictions, website result schema
fields and price remain compatible. The `website-enriched` event is unchanged:
$0.003 per saved successful website, subject to active Store pricing. Alternate
exports do not add billable events and include only saved website results.

The first alphabetically ordered email/phone is only a predictable export
selection, not a recommended or verified contact. CSV safety can add an
apostrophe to leading `+` phone values; JSON remains lossless. No CRM is modified,
and the owner-private browser demo's hosting and audience are unchanged.
